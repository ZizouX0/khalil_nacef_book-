# 🏋️ Practice · How to use this book

:::stats
3 tests | reading, listening, speaking
6 tracks | audio, with exam timing built in
100% | original tasks in the real format
:::

:::big
Practise like the exam: **timer on, no dictionary, no pausing.**
Then check the answers and **name the trap** behind every mistake.
:::

:::steps How to use each exercise
1. **Read the strategy first** in the Guide (Book 1): the one-page summary for that test.
2. **Do the exercise** with a timer. Listening: press play and don't stop the track.
3. **Check** with the answer key at the end of the chapter.
4. **For every mistake**, write the trap's name: a *sospechoso* (reading) or a GUEST (listening).
:::
