# 🗣️ Speaking Tarea 3 · phrases for every message

## 🥪 1 · The frame: the same in EVERY message · 1:30 · goodbye by **1:15**

| | **tú** · friend, family, classmate | **usted** · boss, doctor, company, shop |
|---|---|---|
| 👋 **Hello** | ¡Hola, ___! ¿Qué tal? Soy Aziz. | Buenos días. Me llamo Aziz. |
| 📞 **Why** | **Te dejo este mensaje porque…** · Te llamo para… | Le llamo porque… · Le llamo para… |
| 💬 **Reason** | **Es que…** · Te explico: … | **Es que…** · Le explico: … |
| 👋 **Goodbye** | Muchas gracias. Un abrazo. ¡Hasta pronto! | Muchas gracias por su atención. Un saludo. |

## ⭐ 2 · Find your situation, then use its box

| Situation | Key phrases |
|---|---|
| 🎉 **Invitation · YES** | ¡Muchas gracias por la invitación! **Me encantaría ir.** ¿A qué hora es? ¿Llevo algo? |
| 🎉 **Invitation · NO** | **Lo siento mucho, pero no puedo ir porque…** ¿Qué te parece si quedamos otro día? |
| 🙏 **Ask a favour / help** | **¿Me podrías…?** · ¿Te importaría + inf.? · ¿Tienes tiempo para…? · Te lo agradezco mucho. |
| 📅 **Plan · propose · meet** | **¿Qué te parece si…?** · Podemos + inf. · Quedamos el ___ a las ___ en ___. ¿Te va bien? |
| 🔄 **Change / cancel a plan** | Te llamo para cambiar el plan. · **Al final no puedo…** · ¿Lo dejamos para el ___? |
| 💡 **Advise / recommend** | **Te recomiendo** + inf. · Yo, en tu lugar, iría… · Lo mejor es… · No te pierdas… |
| 📋 **Book / ask for information** | **Quería reservar / pedir…** · ¿Me podría decir…? · ¿Cuánto cuesta? · ¿Está incluido…? · ¿Puede ser el ___? |
| 😠 **Complain** | Le llamo para poner una reclamación. · **Le explico lo que ha pasado:** … · No me parece normal. · **Quiero que** me devuelvan el dinero / lo arreglen. |
| 😔 **Apologize** | **Lo siento mucho.** Perdona / Perdone. · **Te / Le prometo que…** · No volverá a pasar. |
| 🆘 **A problem** | **Tengo un problema:** he perdido… / se me ha olvidado… / no funciona… · ¿Qué puedo hacer? |
| 🤝 **Offer / sell / apply** | Vendo… · Cuesta ___ euros. · **Si te interesa, llámame.** · Creo que soy un buen candidato porque… · Puedo enviarle mi currículum. |
| 🎂 **Thank / congratulate / wish** | **¡Enhorabuena! · ¡Felicidades!** · ¡Feliz cumpleaños! · Muchas gracias por todo, de verdad. · ¡Que te vaya muy bien! |

## 🔗 3 · Glue for any message
- **Links:** además · también · pero · porque · por eso · así que · primero · después · al final
- **Time and place:** el lunes que viene · este fin de semana · el sábado por la mañana · a las ocho · dentro de un par de horas · del viernes al jueves · en mi casa
- **Feelings:** ¡Qué pena! · ¡Qué bien! · Tengo muchas ganas de… · No te preocupes / No se preocupe.

:::trap Your 5 traps (from your recordings)
- ***te amo*** ✗ → ***te llamo***, or the safe opening ***Te dejo este mensaje porque…*** · ***¿Podrías me…?*** ✗ → ***¿ME podrías…?***
- **tú OR usted**, never both · **reuse the task's words** (the name, the subject, *tiempo*, *prometer*…)
- **Ask once, say each point once**, goodbye by **1:15** · ⏱️ **20 s before *Grabar*:** tú or usted? · the name? · which situation box? · one keyword per point ① ② ③
:::
