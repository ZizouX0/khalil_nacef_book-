## Unidad 8 · ¿Qué tiempo hace hoy?

*Fenómenos atmosféricos — Weather* · pp. 38–41

### 1. ¡Fíjese! — Saying what the weather is like

| Español | English |
|---|---|
| ¿Qué tiempo hace hoy? | What's the weather like today? |
| Hace buen tiempo. | The weather is nice. |
| Hace sol. | It's sunny. |
| El cielo está despejado. | The sky is clear. |
| Hace mal tiempo. | The weather is bad. |
| El cielo está cubierto. | The sky is overcast. |
| Está nublado. / Hay nubes. | It's cloudy. / There are clouds. |
| Llueve. / Está lloviendo. | It rains. / It's raining. |
| Nieva. / Cae nieve. | It snows. / Snow is falling. |
| Hay tormenta. | There's a storm. |
| Hay relámpagos. | There's lightning. |
| Hace viento. | It's windy. |
| Hay niebla. | It's foggy. |
| Está helando. / Hay hielo. | It's freezing. / There's ice. |
| Llueve y está saliendo el sol. | It's raining and the sun is coming out. |

### 2. La temperatura — Hot and cold

| Español | English |
|---|---|
| Hace mucho calor. | It's very hot. |
| Hace calor. | It's hot. / It's warm. |
| Hace un poco de frío. | It's a bit cold. |
| Hace mucho frío. | It's very cold. |
| El tiempo está templado. | The weather is mild. |
| La temperatura está alta / baja. | The temperature is high / low. |
| Las temperaturas suben. | Temperatures are rising. |
| Las temperaturas bajan. | Temperatures are falling. |
| El termómetro marca 35 °C. | The thermometer reads 35 °C. |
| más de 35 °C / menos de 15 °C | more than 35 °C / less than 15 °C |
| por encima de los 30 °C | above 30 °C |

### 3. Frases útiles — Useful phrases

| Español | English |
|---|---|
| ¿Qué temperatura hace hoy? | What's the temperature today? |
| Estamos a 10 °C. | It's 10 °C. |
| Hoy hace sol. | It's sunny today. |
| Hace muy buen tiempo, pero mañana va a llover. | The weather is lovely, but tomorrow it's going to rain. |
| No hace ni frío ni calor; el tiempo está templado. | It's neither cold nor hot; the weather is mild. |
