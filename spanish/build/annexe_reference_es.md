# Appendix — Grammar Reference

Quick-reference "cheat-sheet" tables covering the essential grammar of Spanish A1–A2. Keep these handy for fast revision.

## A · The noun group

### A.1 Gender & articles
Every noun is **masculine** or **feminine**. Learn each noun **with its article**.

| | Masculine | Feminine |
|---|---|---|
| **Definite** (the) — singular | **el** libro | **la** casa |
| Definite — plural | **los** libros | **las** casas |
| **Indefinite** (a/some) — singular | **un** libro | **una** casa |
| Indefinite — plural | **unos** libros | **unas** casas |

- Most nouns ending in **-o** are masculine, in **-a** feminine (exceptions: *el día, el mapa, el problema; la mano, la foto*).
- Feminine nouns starting with stressed **a-/ha-** take **el/un** in the singular: *el agua, un águila* (but *las aguas*).

### A.2 Subject pronouns
| Person | Singular | Plural |
|---|---|---|
| 1st | yo (I) | nosotros / nosotras (we) |
| 2nd (informal) | tú (you) | vosotros / vosotras (you, Spain) |
| 3rd / formal | él, ella, usted (he, she, you) | ellos, ellas, ustedes (they, you) |

> Spanish usually **drops** the subject pronoun (the verb ending shows the person): *(Yo) hablo español.*

### A.3 Object pronouns
| | Direct object (DO) | Indirect object (IO) |
|---|---|---|
| me | me | me |
| you (tú) | te | te |
| him/her/it/you(ud.) | **lo / la** | **le** (→ se) |
| us | nos | nos |
| you (vosotros) | os | os |
| them/you(uds.) | **los / las** | **les** (→ se) |

- Placed **before** the conjugated verb: *Lo veo. Te llamo.* — or **attached** to an infinitive/gerund/affirmative imperative: *Voy a verlo. ¡Cómpralo!*
- IO + DO together: IO first; **le/les → se** before lo/la/los/las: *Se lo doy* (I give it to him).

### A.4 Possessives
| | my | your (tú) | his/her/your(ud.) | our | your (vosotros) | their/your(uds.) |
|---|---|---|---|---|---|---|
| Unstressed | mi(s) | tu(s) | su(s) | nuestro/a(s) | vuestro/a(s) | su(s) |
| Stressed | mío/a(s) | tuyo/a(s) | suyo/a(s) | nuestro/a(s) | vuestro/a(s) | suyo/a(s) |

*Es **mi** casa = It's my house. · Es **mía** = It's mine. · un amigo **mío** = a friend of mine.*

### A.5 Demonstratives
| Distance | Masc. sg / pl | Fem. sg / pl | Neuter |
|---|---|---|---|
| this / these (here) | este / estos | esta / estas | esto |
| that / those (there) | ese / esos | esa / esas | eso |
| that / those (far) | aquel / aquellos | aquella / aquellas | aquello |

## B · SER, ESTAR & HAY

### B.1 SER vs ESTAR (both = "to be")
| Use **SER** for… | Use **ESTAR** for… |
|---|---|
| identity: *Es médico.* | location: *Está en casa.* |
| origin: *Soy de México.* | temporary states: *Estoy cansado.* |
| description / lasting traits: *Es alto.* | feelings / moods: *Estamos contentos.* |
| time & price: *Son las tres. Son 40 €.* | result / *-ando* progress: *Está roto. Está comiendo.* |

Present tense:
| | ser | estar |
|---|---|---|
| yo | soy | estoy |
| tú | eres | estás |
| él/ella/usted | es | está |
| nosotros/as | somos | estamos |
| vosotros/as | sois | estáis |
| ellos/ellas/ustedes | son | están |

### B.2 HAY (there is / there are)
One invariable form from *haber*: **hay**. Used with indefinite/quantities: *Hay **un** parque y **dos** bancos.* — Use **está(n)** for definite/known things: *¿Dónde **está** el parque?*

## C · The present tense

### C.1 Regular verbs
| | hablar (-ar) | comer (-er) | vivir (-ir) |
|---|---|---|---|
| yo | hablo | como | vivo |
| tú | hablas | comes | vives |
| él/ella/ud. | habla | come | vive |
| nosotros/as | hablamos | comemos | vivimos |
| vosotros/as | habláis | coméis | vivís |
| ellos/ellas/uds. | hablan | comen | viven |

### C.2 Stem-changing verbs (in the "boot": all but nosotros/vosotros)
| e → ie · querer | o → ue · poder | e → i · pedir |
|---|---|---|
| quiero | puedo | pido |
| quieres | puedes | pides |
| quiere | puede | pide |
| queremos | podemos | pedimos |
| queréis | podéis | pedís |
| quieren | pueden | piden |

*Also: pensar, empezar, preferir, entender (e→ie); dormir, volver, costar, encontrar (o→ue); servir, repetir (e→i).*

### C.3 Key irregular verbs (present)
| | ser | estar | ir | tener | hacer | poner | saber |
|---|---|---|---|---|---|---|---|
| yo | soy | estoy | voy | tengo | hago | pongo | sé |
| tú | eres | estás | vas | tienes | haces | pones | sabes |
| él/ella/ud. | es | está | va | tiene | hace | pone | sabe |
| nosotros | somos | estamos | vamos | tenemos | hacemos | ponemos | sabemos |
| vosotros | sois | estáis | vais | tenéis | hacéis | ponéis | sabéis |
| ellos/uds. | son | están | van | tienen | hacen | ponen | saben |

### C.4 Reflexive (pronominal) verbs
Add the reflexive pronoun (me, te, se, nos, os, se): *llamarse → me llamo, te llamas, se llama, nos llamamos, os llamáis, se llaman.* Common: *levantarse, ducharse, acostarse, sentirse.*

### C.5 GUSTAR-type verbs
Built "back-to-front": the thing liked is the subject; the person is an **indirect object**.
| IO pronoun | + gusta (sg / verb) / gustan (pl) |
|---|---|
| (A mí) **me** | gusta el café / gustan los libros |
| (A ti) **te** | gusta… |
| (A él/ella/ud.) **le** | gusta… |
| (A nosotros) **nos** | gusta… |
| (A vosotros) **os** | gusta… |
| (A ellos/uds.) **les** | gusta… |

*Like this: **encantar** (love), **interesar**, **doler** (hurt), **parecer** (seem), **quedar**.*

## D · Talking about the future & ongoing actions (periphrases)
| Structure | Meaning | Example |
|---|---|---|
| **ir a** + infinitive | be going to | *Voy a estudiar.* |
| **tener que** + infinitive | have to | *Tengo que trabajar.* |
| **hay que** + infinitive | one must (impersonal) | *Hay que practicar.* |
| **querer / poder / saber** + inf. | want / can / know how to | *Quiero viajar. No puedo ir. Sé nadar.* |
| **empezar a** + inf. / **acabar de** + inf. | start to / to have just | *Empiezo a entender. Acabo de llegar.* |
| **estar** + gerundio | be doing (now) | *Estoy comiendo.* |

**Gerundio:** -ar → **-ando** (hablando); -er/-ir → **-iendo** (comiendo, viviendo). Irregular: *leyendo, oyendo, durmiendo, pidiendo, diciendo.*

## E · The past tenses

### E.0 Which past tense? — a quick decision map
Spanish has three main past tenses. Choose by **what kind of past** you mean:

| Tense | Use it for | Typical markers | Example |
|---|---|---|---|
| **Pretérito perfecto** (he hablado) | past linked to *now*; life experience | hoy, esta semana, ya, todavía no, alguna vez | *Hoy **he trabajado** mucho.* |
| **Pretérito indefinido** (hablé) | finished, completed events | ayer, el año pasado, en 2019, hace dos días | *Ayer **comí** paella.* |
| **Pretérito imperfecto** (hablaba) | description, habits, "the background" | antes, siempre, todos los días, de niño | *De niño **jugaba** en la calle.* |

**In a story**, the **imperfecto** paints the scene (weather, time, feelings, what was going on) and the **indefinido** moves the action forward: ***Era** de noche y **llovía** cuando de repente **sonó** el teléfono.*


### E.1 Pretérito perfecto (have + done — recent past / experience)
**haber (present)** + **participio**:
| he · has · ha · hemos · habéis · han | + hablado / comido / vivido |
|---|---|

*Irregular participles:* hacer→**hecho**, decir→**dicho**, ver→**visto**, escribir→**escrito**, poner→**puesto**, volver→**vuelto**, abrir→**abierto**, romper→**roto**, morir→**muerto**. — Time markers: *hoy, esta semana, ya, todavía no, alguna vez.*

### E.2 Pretérito indefinido (finished past — completed actions)
| | hablar | comer / vivir |
|---|---|---|
| yo | hablé | comí / viví |
| tú | hablaste | comiste / viviste |
| él/ella/ud. | habló | comió / vivió |
| nosotros | hablamos | comimos / vivimos |
| vosotros | hablasteis | comisteis / vivisteis |
| ellos/uds. | hablaron | comieron / vivieron |

*Key irregulars (same endings for all):*
| ser / ir | hacer | tener | estar | poder | poner | decir | venir |
|---|---|---|---|---|---|---|---|
| fui | hice | tuve | estuve | pude | puse | dije | vine |
| fuiste | hiciste | tuviste | estuviste | pudiste | pusiste | dijiste | viniste |
| fue | hizo | tuvo | estuvo | pudo | puso | dijo | vino |
| fuimos | hicimos | tuvimos | estuvimos | pudimos | pusimos | dijimos | vinimos |
| fuisteis | hicisteis | tuvisteis | estuvisteis | pudisteis | pusisteis | dijisteis | vinisteis |
| fueron | hicieron | tuvieron | estuvieron | pudieron | pusieron | dijeron | vinieron |

Markers: *ayer, el año pasado, en 2019, hace dos días.*

### E.3 Pretérito imperfecto (background / habits / description in the past)
| | hablar | comer / vivir |
|---|---|---|
| yo | hablaba | comía / vivía |
| tú | hablabas | comías / vivías |
| él/ella/ud. | hablaba | comía / vivía |
| nosotros | hablábamos | comíamos / vivíamos |
| vosotros | hablabais | comíais / vivíais |
| ellos/uds. | hablaban | comían / vivían |

*Only 3 irregulars:* **ser** (era, eras, era, éramos, erais, eran), **ir** (iba, ibas, iba, íbamos, ibais, iban), **ver** (veía…). Markers: *antes, siempre, todos los días, de niño.*

### E.4 Indefinido vs Imperfecto
| Indefinido = the event | Imperfecto = the scene |
|---|---|
| completed, moves the story | habits, repeated actions |
| specific point/number of times | descriptions (weather, age, feelings) |
| *Ayer **comí** paella.* | *De niño **comía** mucho.* |
| *La película **empezó** a las 8.* | *Mientras **llovía**, leía un libro.* |

## F · Imperative & conditional

### F.1 Affirmative imperative (giving instructions)
| | -ar (hablar) | -er (comer) | -ir (vivir) |
|---|---|---|---|
| tú | habla | come | vive |
| usted | hable | coma | viva |
| vosotros | hablad | comed | vivid |
| ustedes | hablen | coman | vivan |

*Irregular **tú** forms:* decir→**di**, hacer→**haz**, ir→**ve**, poner→**pon**, salir→**sal**, ser→**sé**, tener→**ten**, venir→**ven**. — Pronouns attach: *¡Dímelo! ¡Siéntate!*

### F.2 Conditional (would…)
**infinitive + ía, ías, ía, íamos, íais, ían**: *hablaría, comería, viviría.* Same irregular stems as the future: *tendría, podría, haría, diría, saldría, vendría, querría, sabría, habría, pondría.* — Politeness: *¿**Podría** ayudarme? Me **gustaría** un café.*

## G · Comparisons
| Type | Structure | Example |
|---|---|---|
| more … than | **más** + adj + **que** | *Es más alto que yo.* |
| less … than | **menos** + adj + **que** | *Es menos caro que ese.* |
| as … as | **tan** + adj + **como** | *Es tan grande como el otro.* |
| as much/many as | **tanto/a/os/as** + noun + **como** | *Tengo tantos libros como tú.* |
| superlative | **el/la/los/las más** + adj | *Es la ciudad más bonita.* |

*Irregular:* bueno→**mejor**, malo→**peor**, grande→**mayor**, pequeño→**menor**.

## H · Por vs Para
| **PARA** (goal / destination) | **POR** (cause / exchange / movement) |
|---|---|
| purpose: *Estudio **para** aprender.* | reason: *Gracias **por** tu ayuda.* |
| recipient: *Es **para** ti.* | exchange/price: *Lo compré **por** 10 €.* |
| deadline: ***para** el lunes* | duration: *Viví allí **por** dos años.* |
| destination: *Salgo **para** Madrid.* | through/along: *Paseo **por** el parque.* |
| opinion: ***Para** mí, es fácil.* | means: *Hablamos **por** teléfono.* |

## J · Numbers, time & dates
- **0–15:** cero, uno, dos, tres, cuatro, cinco, seis, siete, ocho, nueve, diez, once, doce, trece, catorce, quince.
- **16–29:** dieciséis… veinte, veintiuno, veintidós… **30–90:** treinta, cuarenta, cincuenta, sesenta, setenta, ochenta, noventa (*treinta **y** uno*).
- **100+:** cien / ciento (101 = ciento uno), doscientos, quinientos, mil, un millón.
- **Time:** *¿Qué hora es? — **Es la** una. **Son las** dos y media. Son las tres menos cuarto.* (*de la mañana / tarde / noche*).
- **Days:** lunes, martes, miércoles, jueves, viernes, sábado, domingo. **Date:** *el 5 de mayo de 2024.*
- **Months:** enero, febrero, marzo, abril, mayo, junio, julio, agosto, septiembre, octubre, noviembre, diciembre (all lower-case in Spanish).
- **Ordinals 1st–10th:** primero, segundo, tercero, cuarto, quinto, sexto, séptimo, octavo, noveno, décimo (*primero/tercero* shorten to *primer/tercer* before a masculine noun: *el primer día*).
