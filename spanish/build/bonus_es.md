# Pronunciation & Accents

Good news: Spanish is **phonetic** — once you know the rules, you can read almost any word correctly.

## 1. Vowels — always pure and short
| a | e | i | o | u |
|---|---|---|---|---|
| like *father* | like *bet* | like *see* | like *for* | like *food* |

They never change and never blur (unlike English).

## 2. Consonants that surprise English speakers
| Letter | Sound | Example |
|---|---|---|
| **ñ** | "ny" as in *canyon* | español, mañana |
| **ll** | like "y" in *yes* | llamar, calle |
| **j** | harsh "h" (from the throat) | jamón, trabajo |
| **h** | **silent** | hola, hoy |
| **v / b** | identical — a soft "b" | vivir, bien |
| **r** | a single tap | pero, cara |
| **rr / word-initial r** | rolled/trilled | perro, rojo |
| **c** + e/i | "th" (Spain) / "s" (Lat. Am.) | cinco, gracias |
| **c** + a/o/u | "k" | casa, comer |
| **z** | "th" (Spain) / "s" (Lat. Am.) | plaza, luz |
| **g** + e/i | harsh "h" (= j) | gente, girar |
| **g** + a/o/u | hard "g" | gato, gustar |
| **gue / gui** | hard "g" (u is silent) | guitarra, guerra |
| **güe / güi** | hard "g" + "w" (ü is heard) | pingüino, bilingüe |
| **qu** | "k" (u is silent) | qué, aquí |

## 3. Where's the stress? (3 simple rules)
1. Word ends in a **vowel, -n or -s** → stress the **second-to-last** syllable: *ca-**sa**, ha-**bla**-n, na-**ran**-ja.*
2. Word ends in **any other consonant** → stress the **last** syllable: *ha-**blar**, ciu-**dad**, es-pa-**ñol**.*
3. **Any exception to rules 1–2 carries a written accent (tilde ´):** *ca-**fé**, **ár**-bol, in-glés, can-**ción***.

## 4. The written accent (tilde ´)
- Shows the stressed syllable when it breaks the rules above.
- **Distinguishes identical-looking words:**

| With tilde | Without tilde |
|---|---|
| **tú** (you) | tu (your) |
| **él** (he) | el (the) |
| **sí** (yes) | si (if) |
| **sé** (I know) | se (reflexive) |
| **más** (more) | mas (but) |
| **té** (tea) | te (you, object) |
| **mí** (me) | mi (my) |
| **qué, cómo, dónde, cuándo, quién** (questions/exclamations) | que, como, donde… (statements) |

## 5. Upside-down punctuation
Questions and exclamations **open** with an inverted mark: **¿**Cómo estás**?** · **¡**Qué bien**!**

# Useful Expressions (Expresiones útiles)

Ready-made phrases for real situations. Learn them as whole chunks.

## Greetings & farewells · *Saludos y despedidas*
| Español | English |
|---|---|
| Hola / Buenos días / Buenas tardes / Buenas noches | Hi / Good morning / afternoon / evening |
| ¿Qué tal? / ¿Cómo estás? / ¿Cómo está usted? | How are you? (informal / formal) |
| (Muy) bien, gracias. ¿Y tú? | (Very) well, thanks. And you? |
| Adiós / Hasta luego / Hasta mañana / Nos vemos | Bye / See you later / tomorrow / See you |
| Encantado/a. / Mucho gusto. | Nice to meet you. |

## In class · *En clase*
| Español | English |
|---|---|
| ¿Cómo se dice *table* en español? | How do you say "table" in Spanish? |
| ¿Qué significa "mesa"? | What does "mesa" mean? |
| ¿Puede repetir, por favor? | Can you repeat, please? |
| No entiendo. / ¿Puede hablar más despacio? | I don't understand. / more slowly? |
| ¿Cómo se escribe? | How do you spell it? |

## At a café / restaurant · *En el bar / restaurante*
| Español | English |
|---|---|
| ¿Me pone un café, por favor? | Can I have a coffee, please? |
| Para mí, una caña y unas tapas. | For me, a small beer and some tapas. |
| ¿Qué me recomienda? | What do you recommend? |
| La cuenta, por favor. | The bill, please. |
| ¿Está incluida la propina? | Is the tip included? |

## Shopping · *De compras*
| Español | English |
|---|---|
| ¿Cuánto cuesta / cuánto es? | How much is it? |
| ¿Tiene esto en otra talla / otro color? | Do you have this in another size / colour? |
| ¿Puedo probármelo? | Can I try it on? |
| Solo estoy mirando, gracias. | I'm just looking, thanks. |
| ¿Puedo pagar con tarjeta? | Can I pay by card? |

## Directions · *Direcciones*
| Español | English |
|---|---|
| Perdone, ¿dónde está el baño / la estación? | Excuse me, where is the toilet / station? |
| ¿Cómo llego al centro? | How do I get to the centre? |
| Todo recto, y luego gire a la derecha / izquierda. | Straight on, then turn right / left. |
| ¿Está lejos / cerca de aquí? | Is it far / near here? |

## On the phone & online · *Por teléfono*
| Español | English |
|---|---|
| ¿Diga? / ¿Aló? | Hello? (answering) |
| ¿Puedo hablar con…? | Can I speak to…? |
| Un momento, por favor. | One moment, please. |
| ¿Me da su número / su correo? | Can I have your number / email? |

## Getting by · *Para salir del paso*
| Español | English |
|---|---|
| Perdón / Lo siento. | Excuse me / I'm sorry. |
| No lo sé. | I don't know. |
| ¿Puede ayudarme? | Can you help me? |
| ¡Salud! / ¡Buen provecho! | Cheers! / Enjoy your meal! |
| Estoy de acuerdo. / No estoy de acuerdo. | I agree. / I don't agree. |
